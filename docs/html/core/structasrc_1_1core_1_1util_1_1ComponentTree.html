inlinestatic

指定したパスを正規化する。ただし、"."と".."は""とする。

連続する"/"を一つにし、"."と".."による階層移動を取り除き、先頭と末尾の"/"を取り除く。 "/a/b/./../////c//d/" -> "a/b/c/d"

なお、本来の正規化では"."と".."はそのままになるが、ここでは""としてルートを表すものとする。
