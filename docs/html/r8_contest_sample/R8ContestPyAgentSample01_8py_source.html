169 always_maxABをTrueとした場合は常時最大推力を出力するものとし、spaceからは削除する。

183 - 行動制限について
184 このサンプルでは、いくつかの観点でAIの行動判断を上書きして、一般に望ましくないと思われる挙動を抑制する例を実装している。
185 1. 高度の制限
186 altMinを下限、altMaxを上限とした高度範囲内で行動するように、それを逸脱しそうな場合に制限をかける。
187 spaceが目標高度の場合は単純なクリッピングで範囲を限定する。
188 spaceが目標ピッチ角の場合は、簡易な高度制御則を用いて制限ピッチ角を計算し、それを用いてクリッピングを行う。
189 2. 場外の制限
190 戦域端からdOutLimitの位置に引いた基準ラインの超過具合に応じて目標方位に制限をかける。
191 無限遠で基準ラインに直交、基準ライン上で基準ラインと平行になるようなatanスケールでの角度補正を行う。
192 補正を行う範囲は、戦域端からdOutLimitThresholdの位置に引いたラインからとする。
193 また、東西方向(防衛ライン側)への場外防止を有効化する場合はregardDefenseLineAsPenaltyLineをtrueにすること。
194 第1,2回空戦AIチャレンジは無効、第3,4回空戦AIチャレンジは有効とすることを推奨する。
195 3. 同時射撃数の制限
196 自機の飛翔中誘導弾がmaxSimulShot発以上のときは新たな射撃を行えないようにしている。
197 4. 下限速度の制限
198 速度がminimumVを下回った場合、minimumRecoveryVを上回るまでの間、
199 目標速度をminimumRecovertDstVに固定することで、低速域での飛行を抑制している。
