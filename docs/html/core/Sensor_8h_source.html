102/**
103 * @class IRST
104 * @brief IRセンサ(Infra-Red Search and Track)を表すクラス
105 *
106 * @details
107 * 最も基本的なIRSTモデル。
108 * 目標の方向(と方向変化率)のみをTrack2Dとして観測できる。
109 *
110 * 複数の戦闘機が生成したTrack2Dのtruthを照合してペアを特定して三角測量を行なうことを防ぐため、
111 * truthにはランダムなUUIDを入れる。
112 *
113 * - 探知誤差を無視し、真の値を航跡化する。
114 * - ジンバル等の首振りを無視し、瞬時視野角を考慮しない。
115 *
116 * 赤外放射強度(irRadiationIntensityScale)が1の目標に対する基準探知距離をパラメータとして、
117 * 赤外放射強度の平方根に比例する最大探知距離内に目標がいる場合に探知できるものとする。
118 */

124 //internal variables
